📋 PREREQUISITES

🚀 INSTALLATION STEPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Navigate to Project Directory
--------------------------------------
cd d:/inn/Innovative/TISAP

STEP 2: Install Dependencies
-----------------------------
npm install

This will install:
  - Next.js 14
  - React 18
  - TypeScript
  - Tailwind CSS
  - Recharts (for charts)
  - Lucide React (for icons)
  - Other utilities

STEP 3: Verify Environment Variables
-------------------------------------
Check that .env.local contains:
NEXT_PUBLIC_API_URL=http://localhost:8000

STEP 4: Start Development Server
---------------------------------
npm run dev

The app will start at: http://localhost:3000

🎯 FIRST TIME USAGE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open browser: http://localhost:3000
2. You'll see the login page
3. Select a role:
   
   👤 ADMIN
   ├─ View organization-wide metrics
   ├─ Filter by department
   ├─ Assign remedial training
   └─ Export reports
   
   👥 MANAGER
   ├─ View team-specific data
   ├─ Download CSV/PDF reports
   └─ Monitor team members
   
   👨‍💼 EMPLOYEE
   ├─ View personal security score
   ├─ See event timeline
   ├─ Read security tips
   └─ Track score history

4. Click "Continue" to access your dashboard

📡 CONNECTING TO FASTAPI BACKEND
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Required Endpoints:
-------------------
GET  /api/data              → Dashboard metrics
GET  /api/users             → All users (admin only)
GET  /api/users/:id         → Individual user data
POST /api/events            → Create security event
POST /api/assign-remedial   → Assign training

CORS Configuration (FastAPI):
------------------------------
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:3000"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

Note: If FastAPI is not running, the app will use mock data automatically!

🔍 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: Port 3000 already in use
Solution: Next.js will prompt to use another port (e.g., 3001)

Problem: API connection errors
Solution: 
  - Check FastAPI is running on port 8000
  - Verify CORS configuration
  - App will fall back to mock data if API unavailable

Problem: TypeScript errors in IDE
Solution: These will resolve after running "npm install"

Problem: Build errors
Solution: 
  rm -rf node_modules .next
  npm install
  npm run dev
